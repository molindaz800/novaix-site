Datos que tratamos

Podemos recoger nombre y apellidos, correo electronico, empresa o proyecto, fecha y hora de una cita y la informacion que el usuario incluya voluntariamente en formularios, mensajes o solicitudes de reunion.

No solicitamos datos especialmente protegidos. Pedimos exclusivamente la informacion necesaria para atender cada solicitud o prestar el servicio acordado.

Finalidades del tratamiento

Tratamos los datos para gestionar solicitudes de contacto y reuniones, responder consultas comerciales, coordinar servicios, prestar soporte y operar integraciones autorizadas por el usuario, incluidas las relacionadas con redes profesionales y herramientas empresariales.

Base juridica

La base juridica es el consentimiento del usuario, la aplicacion de medidas precontractuales solicitadas y, cuando exista una relacion contractual, la ejecucion del contrato. Cuando una norma lo exige, el tratamiento tambien puede basarse en el cumplimiento de una obligacion legal.

Proveedores y destinatarios

Utilizamos proveedores tecnologicos necesarios para prestar el servicio, como sistemas de agenda, correo, alojamiento, automatizacion, CRM e integraciones expresamente autorizadas. Estos proveedores actuan como encargados del tratamiento cuando corresponde.

No vendemos datos personales ni los cedemos a terceros con fines publicitarios. Solo se comunican cuando resulta necesario para prestar el servicio o existe una obligacion legal.

Transferencias internacionales

Algunos proveedores pueden tratar datos fuera del Espacio Economico Europeo. Cuando ocurre, aplicamos mecanismos reconocidos por la normativa, como decisiones de adecuacion o Clausulas Contractuales Tipo aprobadas por la Comision Europea.

Plazos de conservacion

Conservamos los datos mientras sean necesarios para la finalidad indicada, exista una relacion comercial o contractual, o deban mantenerse para cumplir obligaciones legales. Despues se eliminan o bloquean de forma segura durante los plazos legalmente exigibles.

Para ejercer tus derechos, indica tu solicitud y los datos necesarios para identificarte. info@novaix.es

Seguridad de la informacion

Aplicamos medidas tecnicas y organizativas proporcionales al riesgo, entre ellas minimizacion de datos, control de accesos, revision de proveedores, cifrado en transito cuando el servicio lo permite, separacion de credenciales y registro de eventos relevantes.

Inteligencia artificial y datos del cliente

Los datos facilitados para analizar solicitudes, preparar demostraciones, configurar agentes o ejecutar integraciones se utilizan unicamente para la finalidad acordada. No se emplean para entrenar modelos publicos sin autorizacion expresa.

Actualizaciones de esta politica

Podemos actualizar esta politica para reflejar cambios legales, tecnicos o de servicio. La version vigente estara disponible permanentemente en esta pagina, junto con la fecha de su ultima actualizacion.
