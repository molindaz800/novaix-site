Datos que recogemos

Podemos recoger nombre y apellidos, correo electronico, empresa o proyecto, fecha y hora de una cita y la informacion que el usuario incluya voluntariamente en formularios, mensajes o solicitudes de reunion. No solicitamos datos especialmente protegidos.

Finalidad del tratamiento

Tratamos los datos para gestionar solicitudes de contacto y reuniones, responder consultas comerciales, coordinar servicios, prestar soporte y operar integraciones autorizadas por el usuario, incluidas las relacionadas con redes profesionales y herramientas empresariales.

Base juridica

La base juridica es el consentimiento del usuario, la aplicacion de medidas precontractuales solicitadas y, cuando exista una relacion contractual, la ejecucion del contrato.

Herramientas externas y destinatarios

Utilizamos proveedores tecnologicos necesarios para prestar el servicio, como sistemas de agenda, correo, alojamiento, automatizacion, CRM e integraciones autorizadas. Estos proveedores actuan como encargados del tratamiento cuando corresponde. No cedemos datos a terceros salvo obligacion legal.

Transferencias internacionales

Algunos proveedores pueden tratar datos fuera del Espacio Economico Europeo. Cuando ocurre, se aplican mecanismos reconocidos por la normativa, como decisiones de adecuacion o Clausulas Contractuales Tipo.

Conservacion

Conservamos los datos mientras sean necesarios para la finalidad indicada, exista una relacion comercial o contractual, o deban mantenerse para cumplir obligaciones legales. Despues se eliminan o bloquean de forma segura.

Derechos

El usuario puede solicitar acceso, rectificacion, supresion, oposicion, limitacion y portabilidad escribiendo a info@novaix.es. Tambien puede presentar una reclamacion ante la Agencia Espanola de Proteccion de Datos.

Seguridad

Aplicamos medidas tecnicas y organizativas proporcionales al riesgo, entre ellas minimizacion de datos, control de accesos, revision de proveedores, cifrado en transito cuando el servicio lo permite y registro de eventos relevantes.

Inteligencia artificial y datos del cliente

Los datos facilitados para analizar solicitudes, preparar demostraciones, configurar agentes o ejecutar integraciones se utilizan unicamente para la finalidad acordada. No se emplean para entrenar modelos publicos sin autorizacion expresa.

Cambios en esta politica

Podemos actualizar esta politica para reflejar cambios legales, tecnicos o de servicio. La version vigente estara disponible permanentemente en esta pagina.
